Language power First we have Turing complete languages, which are all equally powerful. Then we have non Turing complete languages with unbounded inputs. In this case, the power is given by how quickly the number of steps grow given the length of the input. But we also have different types of functions that can be computed by these languages which are not strictly more or less powerful, not all of them are going to be able to compute the same function as the other language. Then we have languages with a maximum input length for any given program. In this case I would say power can be measured as how quickly the maximum input length grows for each additional symbol in the program. Like in the previous case, not all of them are going to be able to compute the same function as the other language. Restrictions Traditionally classes are defined by time and space resource bounds as a function of the input length, but could also be defined in terms of the program and the input itself, and could be defined as a restriction of what intermediate steps the input is allowed to take. This allow us to define a strictly larger number of classes for all programs up to a certain size compared to the traditional time and space restrictions based on the input lenght. Classes The largest sub-class possible is that of non Turing complete languages. For some languages, it will be impossible to determine whether they belong to this one or to the Turing complete class, becuse it would be equivalent to solving the halting problem.
